# ערוץ האמונה - haemuna.co.il

אתר סטטי (HTML + CSS בלבד, בלי מסגרות ובלי npm) של הרב יעקב מאור.
מתפרסם ב-GitHub Pages מענף `main`, על הדומיין `haemuna.co.il` שה-DNS שלו בקלאודפלייר.

## המבנה

```
pages/*.html        גוף העמוד בלבד (בלי כותרת עליונה, ניווט ותחתית)
_shell-head.html    הכותרת, הניווט ותגי ה-meta שכל עמוד חולק
_shell-foot.html    התחתית
data/shiurim.json   מקור האמת לעמוד השיעורים
build.py            מרכיב מכל אלה את קבצי ה-HTML בשורש
assets/style.css    גיליון העיצוב
```

**לא עורכים ידנית את קבצי ה-HTML שבשורש** - הם נוצרים מחדש בכל בנייה ונדרסים.
עורכים את `pages/` או את `data/`, ואז:

```
py build/haemuna-site/build.py
git add -A && git commit -m "..." && git push
```

הפריסה אוטומטית: כל דחיפה ל-`main` עולה לאוויר תוך כדקה.

## הוספת שיעור

השיעורים הם החלק שמתעדכן הכי הרבה, ולכן הם יושבים ב-`data/shiurim.json`
ולא ב-HTML. שתי קבוצות: `kollel` (רבני הכולל) ו-`guests` (רבנים אחרים).

```json
{
  "rav": "הרב פלוני אלמוני",
  "title": "שם השיעור",
  "url": "https://...",
  "why": "למה השיעור הזה נמצא כאן, בקול של יעקב.",
  "added": "2026-09-06",
  "approved": true
}
```

**`approved` הוא לב העניין.** שיעור של רב אחר מתפרסם רק אחרי שיעקב אישר
שיש בידו רשות מאותו רב. רשומה עם `approved: false` נשמרת בקובץ ולעולם
לא מגיעה לעמוד, כך שאפשר לחנות קישור בבטחה בזמן שההיתר בדרך.

## מה עוד לא סגור

עמוד הספרים מציג "בקרוב" במקום כפתור רכישה, כי הסליקה של רשימו עדיין
בהקמה. ברגע שדף המכירה במורנינג קיים, מחליפים את שלושת ה-`<span class="soon">`
ב-`pages/books.html` בקישור אמיתי ובונים מחדש.
